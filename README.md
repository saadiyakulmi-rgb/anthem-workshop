National Anthem App – Git & GitHub Workshop

1. Project Overview

The National Anthem App is a simple web application developed using Python and Flask. It displays the Indian National Anthem through a simple and readable web interface.

This project is part of a Git and GitHub workshop. It helps students understand version control, collaboration, repository management, branching, merging and conflict resolution.

2. Project Objectives

- Develop a simple web application using Flask.
- Understand Git and GitHub version control.
- Practise creating and managing branches.
- Learn how to push and pull changes.
- Understand merging and resolving conflicts.
- Learn how multiple team members can collaborate on one project.

3. Technologies Used

6. Installation and Execution

Prerequisites

- Python 3
- Git
- A code editor such as Visual Studio Code
- Internet connection

Step 1: Clone the repository

git clone https://github.com/saadiyakulmi-rgb/anthem-workshop.git

Step 2: Open the project folder

Open the downloaded "anthem-workshop" folder in Visual Studio Code.

Step 3: Install dependencies

The application uses Flask. Install the required dependency before running the application.

Step 4: Run the application

Run the Flask application using your configured Python environment.

Step 5: Open the application

If the application starts successfully, open the local address shown by Flask in your web browser.

The commands above are documentation examples, not instructions to run Linux commands. Follow the Windows GUI setup separately.

8. Git and GitHub Workshop Exercises

The following exercises are included in the workshop.

8.1 Repository Creation and Cloning

Created a GitHub repository to store the National Anthem project and practised obtaining a copy of the repository.

8.2 Push and Pull Operations

Practised sharing changes between team members using GitHub.

8.3 Branch Creation

Created separate branches to practise independent development.

Example:

git switch -c feature/second-stanza

8.4 Adding and Committing Changes

Practised tracking changes and saving them as commits.

git add .
git commit -m "Add changes"

8.5 Merging Branches

Practised combining changes from a feature branch into the main branch.

8.6 Merge Conflict Resolution

Practised identifying and resolving conflicts when multiple team members modify the same content.

8.7 Project History

Reviewed commit history to understand how changes were made and contributed by team members.

9. Conclusion

The National Anthem App workshop provides practical experience in developing a simple Flask application and managing project changes using Git and GitHub. It demonstrates how team members can collaborate, maintain project history, work with branches and resolve merge conflicts.
